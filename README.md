Modern Resume Generator (C++)
A simple command-line tool built with C++ that generates a clean and formal resume layout.

How to Use
Input Data: Choose Option 1 to enter your details.
Generate: Choose Option 2 to view the formatted resume.

Features
Word Wrap: Keeps long text organized.
Clean Layout: Professional headers and dividers.
Error Handling: Prevents crashes from invalid inputs.

Tech Stack
- Language: C++
- Tools: VS Code
